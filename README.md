- 🎨 **Modern & Trustworthy Aesthetics** — Clean typography, glassmorphism, responsive sidebar navigation, and subtle micro-animations.
- 🌓 **Dark & Light Mode** — Seamless theme toggle with local preference caching.

- 📋 **One-Click Contact** — Integrated developer contact card with instant email copy.
- 🖨️ **Print & PDF Friendly** — Clean print styling for export and compliance records.

## How to Enable GitHub Pages
1. Push this repository to GitHub (`main` branch).
2. Go to your GitHub repository **Settings** &rarr; **Pages**.
3. Under **Build and deployment** &gt; **Source**, select **Deploy from a branch**.
4. Choose Branch: `main` and Folder: `/ (root)`, then click **Save**.
5. Your privacy policy will be live at `https://<your-username>.github.io/TeleVault-Privacy-Policy/`.
