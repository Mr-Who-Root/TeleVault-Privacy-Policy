# TeleVault - Privacy Policy Website

Official privacy policy website for **TeleVault (Free & Pro Editions)**, developed by **Govind S R**.

Hosted on GitHub Pages: [https://mr-who-root.github.io/TeleVault-Privacy-Policy/](https://mr-who-root.github.io/TeleVault-Privacy-Policy/)

## Features
- 🚀 **100% Static & Lightweight** — No dependencies or build steps required. Ready for GitHub Pages deployment.
- 🎨 **Matches the App** — Uses TeleVault's own ink-and-brass design system (colors, Space Grotesk / Inter / IBM Plex Mono) and the app icon.
- 🌓 **Dark & Light Mode** — Follows the system setting, with a toggle that remembers the visitor's choice.
- 📱 **Mobile & Desktop Responsive** — Optimized for all viewports, compliance checkers, and app store reviewers.
- 📋 **One-Click Contact** — Integrated developer contact card with instant email copy.
- 🖨️ **Print & PDF Friendly** — Clean print styling for export and compliance records.

## How to Enable GitHub Pages
1. Push this repository to GitHub (`main` branch).
2. Go to your GitHub repository **Settings** &rarr; **Pages**.
3. Under **Build and deployment** &gt; **Source**, select **Deploy from a branch**.
4. Choose Branch: `main` and Folder: `/ (root)`, then click **Save**.
5. Your privacy policy will be live at `https://<your-username>.github.io/TeleVault-Privacy-Policy/`.
